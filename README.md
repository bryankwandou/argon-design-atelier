# Antigravity Argon Atelier — Enterprise IT Spatial Design Systems

A private engineering and spatial design atelier custom-crafted for high-reliability IT enterprises, fintech leaders, and autonomous AI systems. Built with extreme attention to visual craft, kinetic spring-physics micro-interactions, WCAG 2.1 AA accessibility, and zero-reflow rendering pipelines.

## Architectural Highlights

- **120 FPS Spatial Canvas Viewports**: HTML5 sub-pixel canvas rendering for distributed systems, node topologies, and multi-agent offices.
- **Zero-Trust Tokenized Design System**: Centralized CSS custom properties in `tokens.css` with 100% dark/light mode parity and zero arbitrary hardcoded hex codes.
- **Bilingual Localization Runtime**: Instant seamless switching between Bahasa Indonesia (`id`) and English (`en`) without page reloads.
- **Interactive Atelier Parameter Simulator**: Real-time visual parameter test laboratory allowing prospective enterprise partners to evaluate FPS limits, mesh densities, and architectural palettes live.
- **Kinetic Micro-Interactions**: Custom trailing blend cursor, 00-100% percentage loader, and spring-physics state dispatchers.
- **Enterprise Case Records**: Battle-tested architectural showcases across FinTech Zero-Trust, Autonomous Cloud Topologies, High-Velocity Data Lakehouses, and AI Multi-Agent Consoles.

## Technology Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Tokenized Design Variables
- **Icons**: Lucide React
- **Build Tooling**: Vite 6, TypeScript Compiler
